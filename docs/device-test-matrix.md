# Pikmin Helper 真机测试矩阵

## 版本边界

地图、定点、摇杆、路线、资料库、GPX、手绘、Live Activity 和新版视觉层级在所有受支持系统（iOS/iPadOS 17.4 及以上）一致。系统版本只改变“首次配对”这一段：

| 系统 | 首次配对 | 预期 UI |
| --- | --- | --- |
| iOS 17.4–26 | 电脑生成并导入 pairing file | 向导显示电脑方案，不显示本机 1–7 步入口 |
| iOS 27+ | 本机 Pairable Host；电脑文件为备用 | 向导与设置显示本机 1–7 步入口 |

因此并不是“只有 iOS 27 才有新版 UI”；新版主界面向旧系统开放，只有本机配对能力按系统分支。

## 每次提交前自动检查

```bash
Tools/verify-pikmin-helper.sh
```

脚本会验证四个 plist/隐私清单，构建主 App、单元测试、VPN Extension 与 Live Activity Extension，并确认两个 Extension 和隐私清单进入最终 App 包。

当前 `idevice` 静态库只有 iphoneos arm64 slice，因此 UI 测试目标会被 `build-for-testing` 编译检查，但不能链接到 Simulator 运行；两条 UI 用例需在可用真机上运行。补齐 simulator slice 后，可直接把目标切到 iOS Simulator 执行。

## 真机用例

| 区域 | iOS 17.4–26 | iOS 27+ | 通过条件 |
| --- | --- | --- | --- |
| 首次向导 | 导入电脑 pairing file | 完成 1–7 步本机配对 | 完成后进入首页，重启不重复弹出 |
| VPN/通道 | 连接内置 VPN | 连接内置 VPN | 状态胶囊显示已准备；VPN 不访问外部服务器 |
| 定点 | 地图/搜索/坐标传送 | 同左 | 前台 1 秒刷新，锁屏后台 3 秒刷新；恢复真实定位成功 |
| 摇杆 | 方向、暂停、巡航 | 同左 | 速度/坐标连续；切 App 后仍运行；回前台立即验证连接 |
| 自动重连 | 运行中短暂断开 VPN | 同左 | 1/2/4/8 秒重试；恢复后续跑；失败才暂停并通知 |
| 路线 | 步道/道路、闭环、直线降级 | 同左 | MapKit 结果正确；道路模式不改变成驾车速度 |
| 文件 | GPX 导入/导出、手绘保存 | 同左 | 精确轨迹保存后点数不丢失，导出的 GPX 可再次导入 |
| 资料库 | 收藏/最近/路线增删选用 | 同左 | 最近位置 25 米去重、最多 12 条 |
| Live Activity | 锁屏；支持机型灵动岛 | 同左 | 显示状态、步数、距离、速度、坐标；结束后 30 秒内消失 |
| 隐私 | 查看设置中的网络说明 | 同左 | 启动不请求 DDI；只有确认后访问允许域名；无分析请求 |
| 能耗 | 30 分钟定点与路线 | 同左 | 无会话时音频/定位停止；会话中无重复 lease 或高频健康检查 |

## 安装到指定设备

```bash
xcrun devicectl list devices
Tools/install-pikmin-helper.sh <device-identifier>
```

设备必须处于 `available` 状态、已解锁并开启开发者模式。iOS 27 的本机配对功能仍需在 App 内完成，不等同于 Mac 为安装所需的开发签名连接。
