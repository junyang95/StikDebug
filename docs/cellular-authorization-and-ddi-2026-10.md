# 蜂窝网络授权与 DDI 安装 — 0.1.6 (7)

## VIP 授权

- Wi‑Fi 与蜂窝网络切换，即使系统一直报告网络可用，也会触发失败请求的恢复检查。同一网络状态不会重复触发。
- 请求明确允许蜂窝网络及低数据模式；首次网络权限仍由真实请求触发，允许后恢复验证。
- 连接中断、DNS、超时及 HTTP 502/503/504 最多尝试 3 次，间隔 1、2 秒；每次创建新会话。整次服务器验证仍受 60 秒期限控制。
- 以前验证成功的设备，可使用与同一配对内容绑定的签名记录重新联网验证，无需再次等待本机 VPN 读取 UDID。过期记录只提供设备身份，不授予离线使用权。
- 3 天离线期限、会员到期限制、签名与 nonce 校验、封禁清理缓存规则保留。网络失败不会更新离线期限，也不会创建新授权。
- 诊断报告增加请求阶段及 URL/HTTP 错误码，不加入 UDID、请求头或响应内容。

这些修改针对客户端可确认的恢复缺口。尚未取得买家的运营商、具体错误码与失败日志，不能据此确定其所有失败都来自同一个原因。

## DDI 安装

首页与设置中的 DDI 检查项可以打开安装页；警告下另有明确的「打开 DDI 安装」按钮。

用户点击「下载并安装 DDI」后，依次检查配对、连接内置 VPN、下载缺少的文件、挂载并确认设备端挂载状态。下载显示当前文件进度，可取消；原生挂载开始后需等待完成。关闭安装页不会取消任务，App 需保持前台。

完整下载文件保留供重试。失败时可重新下载全部文件。下载只接受指定 HTTPS 域名，拒绝站外跳转、空文件、维护页及无效清单。下载成功后才替换已有文件；挂载失败不会显示安装成功。原有自动挂载与引导安装互斥，重复点击也不会创建并行安装。

DDI 仍为可选功能，环境检查不会用它阻止定位模拟。

## 真机复测路径

1. 已授权设备关闭 Wi‑Fi，使用 4G/5G 点击重新验证；再在请求中切换 Wi‑Fi/蜂窝网络。
2. 首装允许网络访问后确认自动验证；关闭网络时确认有效缓存可继续使用，恢复网络后自动重试。
3. 点击首页 DDI 警告下的安装入口，安装并检查挂载结果；断网时应显示失败或等待，恢复后重试应复用完整文件。
4. 若授权仍失败，从设置导出诊断报告，检查「授权请求诊断」的阶段和错误码，再区分运营商 DNS/TLS/服务器可达性与本机设备连接问题。
